## 👋 About Me

I'm a **Software Engineer from Sri Lanka 🇱🇰** and a graduate of the **Informatics Institute of Technology (IIT)**, affiliated with the **University of Westminster** — BEng (Hons) Software Engineering, Second Class Upper.

- 💼 Currently working as a **Backend Java Developer at [FortunaGlobal](#)**, building backend features for financial systems
- 🏥 Previously a **Software Engineer Intern at Cambio Software Engineering** (Jun 2024 – Jun 2025), working on production healthcare systems
- 🏭 I love building real software for real businesses — several of my systems run daily in Sri Lankan plywood and timber factories
- 👁️ Interested in **computer vision & ML** — my final-year thesis detects plywood defects in real time
- 📫 Reach me at **chandupamarapana@gmail.com**

## 💼 Experience

**Backend Java Developer — FortunaGlobal** · *Jul 2026 – Present*

Worked in the core framework team of a large enterprise healthcare platform. Led a Java LTS and Spring framework upgrade across a 50,000+ line legacy codebase, restoring CI pipeline stability, and implemented i18n support for multi-language international rollout.
